# 🔥 GEOframe — Active Repositories Status

Below is a first prototype of a “module status board” with clickable badges for the most active GEOframe repositories.

Badge meaning:
- ⭐ Stars = popularity
- 🍴 Forks = reuse
- 👥 Contributors = community
- 🕒 Last commit = "is this alive?"
- 📈 Activity = commits in the last year
