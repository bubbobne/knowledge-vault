# 🌧️ The **alpha** Function and Its Link to Moore (1985)

This note explains how the **alpha** function used in our code is directly derived from the probability-distributed soil moisture model introduced by **Moore (1985)**.  
In simple terms:

> **alpha(P, Sₙ) = runoff generated by rainfall P, divided by P**,  
> computed according to the capacity-distribution theory of Moore.

---

## 📚 Reference

**Moore, R.J. (1985).**  
*The Probability-Distributed Principle and Runoff Production at Point and Basin Scales.*  
**Hydrological Sciences Journal**, 30(2), 273–297.  
<https://doi.org/10.1080/02626668509490989>
[also in yhis vault](Hydrology/Probability-Distribuited_runoff.md)
---

## 1. Background: Moore’s Probability-Distributed Principle

Moore (1985) models the catchment as a set of points with varying soil storage capacities $c$, distributed according to a cumulative distribution function $F(c)$.

For a rainfall pulse $P$ falling on a catchment with mean antecedent storage $S_n$, Moore derives:

- the **runoff volume** generated by that pulse, $U(P; S_n)$  
- the **updated storage**, $S_{n+1}$

Our function **alpha** normalizes Moore’s runoff expression:

$$
\\alpha(P, S_n) = \\frac{U(P; S_n)}{P}
$$

which represents **the fraction of rainfall that becomes direct runoff**.

---

## 2. Parameter Correspondence

In Moore’s formulation, the soil storage capacity has maximum value $C_{\\max}$ and shape parameter $b$.  
Moore shows that:

$$
S_{\\max} = \\frac{C_{\\max}}{b+1}
\\quad \\Rightarrow \\quad
C_{\\max} = S_{\\max}(b+1)
$$

In code:

```java
Cmax = Smax * (b + 1);
```
Thus the implementation follows Moore exactly.

---

## 3. Recovering the Current Threshold Capacity $c_t$

For a known mean storage $S_n$, Moore links $S_n$ to the capacity threshold $c_t$ via:
$$
S_n =
\frac{C_{\max}}{b+1}
\left[
1 -
\left(
1 - \frac{c_t}{C_{\max}}
\right)^{b+1}
\right]
$$

Solving for $c_t$ yields:

Always show details

```java
ct_prev = Cmax * (1 - (1 - (b+1)*Sn/Cmax)^(1/(b+1)))
```

This computes the capacity threshold corresponding to the current storage.

---

## 4. First Runoff Component: Exceeding Total Capacity

The first part of the runoff occurs when rainfall exceeds the remaining catchment capacity:

$$
UT1 = \max\big(P - (C_{\max} - c_t),\, 0\big)
$$

In code:

Always show details

```java
UT1 = max(P - Cmax + ct_prev, 0);
```

This corresponds to rainfall falling on areas already saturated to capacity.

---

## 5. Updated Storage After Rainfall

After removing `UT1`, the updated threshold capacity is:

Always show details
```java
dummy = (ct_prev + P - UT1)/Cmax;
```


This is inserted into Moore’s storage-capacity relationship to compute:

$$
S_{n+1} =
\frac{C_{\max}}{b+1}
\left[
1 -
\left(
1 - \frac{c'}{C_{\max}}
\right)^{b+1}
\right]
$$

implemented as:

Always show details

```java 
xn = Cmax/(b+1) * (1 - (1 - dummy)^(b+1));
```

---

## 6. Second Runoff Component: Rainfall Not Absorbed by Storage

The remaining runoff is:
$$
UT2 = \max\big(P - UT1 - (S_{n+1} - S_n),\, 0\big)
$$

which appears in the code as:

Always show details

```java
UT2 = max(P - UT1 - (xn - Sn), 0);
```


It represents rainfall not accommodated by the updated storage.

---

## 7. Definition of the **alpha** Function

Total runoff generated by the rainfall pulse:
$$
U(P; S_n) = UT1 + UT2
$$


The **alpha** value is:

$$
\alpha = \frac{UT1 + UT2}{P}
$$


i.e., the **runoff coefficient** predicted by the Moore (1985) capacity-distribution model for the current timestep.

---

## 🔎 Summary

- The **alpha** function is a numerical implementation of the soil-capacity distribution principle of Moore (1985).
    
- `ct_prev`, `UT1`, `UT2`, and the update of storage correspond exactly to Moore’s equations.
    
- Alpha expresses the **fraction of rainfall that becomes direct runoff**.
    
- When the catchment is near saturation or rainfall is high, the function correctly yields $\alpha \approx 1$, consistent with the theory.
